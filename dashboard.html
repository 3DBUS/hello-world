Connect Google Drive

Your transactions will be saved to a file in your Google Drive (wealth-dashboard-data.json) and stay in sync across all your devices.

Before you start: Google OAuth requires this page to be served over HTTP, not opened directly from a file.
Run a local server first: python3 -m http.server 8080 then open http://localhost:8080/dashboard.html
  1. Go to console.cloud.google.com and create a new project
  2. Search for Google Drive API and click Enable
  3. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID
  4. Choose Web application. Under Authorized JavaScript origins add http://localhost:8080
  5. Click Create, then copy the Client ID (ends in .apps.googleusercontent.com)
